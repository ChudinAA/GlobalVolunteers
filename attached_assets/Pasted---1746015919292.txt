Создать сайт на русском и английском языках для благотворительной организации, которая ведет волонтерские проекты по всему миру.

Разделы сайта:
- Главная
- Проекты -> детальная карточка проекта
- Волонтерам
- Организациям
- О нас
- Контакты.

Формы для заполнения на сайте:
- Хочу участвовать
- Стать партнером

На Главной странице:
- Шапка с фоновым видео.
- Интерактивная карта с проектами: точки различаются по цвету по направлениям проектов: красным - направление проекта “Медицина”, желтым - направление проекта “Образование”, синим - направление проекта “Спорт”, зеленым - направление проекта “Экология”.
- Слева от карты - список из названий направлений проектов, написаны шрифтом того же цвета, как обозначены на карте (референс): красным - направление проекта “Медицина”, желтым - направление проекта “Образование”, синим - направление проекта “Спорт”, зеленым - направление проекта “Экология”.
- При этом список расположен и оформлен так, чтобы было интуитивно понятно, что можно нажать на наименование сферы проекта.
- При нажатии на сферу проекта - она подсвечивается и на карте остаются только те проекты, направление которых совпадает с выбранной сферой из списка слева (то есть если кликнуть сферу “Экология”, то на карте останутся только те точки, которые относятся к проектам в сфере экологии). Возможно выбрать несколько слов, повторное нажатие - снимает выделение.
- При наведении на точку высвечивается карточка проекта

Состав карточки проекта:
- Фото проекта (занимает не более ⅙ карточки)
- Наименование проекта
- Краткое описание проекта
- Срок проведения
- Локация (наименование страны проведения проекта)
- Направление проекта (возможные варианты: Медицина, Образование, Спорт, Экология)
- Куратор (ФИО, телефон, почта)
- Кнопка “Подробнее”
